# SDC310 Shopping Cart Project

A PHP based shopping cart application developed for the ECPI SDC310 course. The project demonstrates basic product management, session based cart functionality, and order calculations.

## Features

* Display available products
* Add products to the cart
* Remove products from the cart
* Increase or decrease product quantities
* Prevent quantities from dropping below zero
* View cart contents
* Calculate product totals
* Calculate 5% sales tax
* Calculate 10% shipping and handling
* Calculate the final order total
* Checkout by clearing the cart and returning to the product catalog

## Technologies

* PHP
* HTML
* CSS
* MySQL
* PHP Sessions
